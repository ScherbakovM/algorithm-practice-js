## 1. Массивы и базовые алгоритмы

### Задача 1. Сумма элементов массива

Напиши функцию `sumArray(arr)`, которая возвращает сумму всех чисел массива.

```js
const arr = [4, 7, 2, 9, 3];
```

### Задача 2. Минимум и максимум

Напиши функцию `findMinMax(arr)`, которая находит минимальное и максимальное число без использования `Math.min()` и `Math.max()`.

```js
const arr = [8, 3, 12, -4, 7, 1];
```

### Задача 3. Подсчёт чётных чисел

Напиши функцию `countEven(arr)`, которая возвращает количество чётных чисел.

```js
const arr = [1, 2, 4, 7, 8, 10, 13];
```

### Задача 4. Разворот массива

Напиши функцию `reverseArray(arr)`, которая разворачивает массив без использования `reverse()`. Исходный массив не должен изменяться.

```js
const arr = [1, 2, 3, 4, 5];
```

### Задача 5. Удаление дубликатов

Напиши функцию `removeDuplicates(arr)`, которая удаляет повторяющиеся элементы, сохраняя порядок первого появления.

```js
const arr = [3, 1, 3, 5, 1, 7, 5, 9];
```

### Задача 6. Второй максимум

Напиши функцию `secondMax(arr)`, которая возвращает второе по величине уникальное число. Если такого числа нет, возвращай `null`.

```js
const arr = [10, 5, 8, 10, 3, 8, 7];
```

### Задача 7. Частота элементов

Напиши функцию `countElements(arr)`, которая подсчитывает количество повторений каждого значения.

```js
const arr = ["a", "b", "a", "c", "b", "a"];
```

### Задача 8. Объединение отсортированных массивов

Напиши функцию `mergeSortedArrays(a, b)`, которая объединяет два отсортированных массива в один отсортированный. Не используй `sort()`.

```js
const a = [1, 4, 7, 10];
const b = [2, 3, 8, 12];
```

### Задача 9. Перемещение нулей

Напиши функцию `moveZeros(arr)`, которая перемещает все нули в конец массива, сохраняя порядок остальных элементов.

```js
const arr = [0, 1, 0, 3, 12, 0, 5];
```

### Задача 10. Циклический сдвиг массива

Напиши функцию `rotateRight(arr, k)`, которая сдвигает элементы вправо на `k` позиций.

```js
const arr = [1, 2, 3, 4, 5];
const k = 2;
```

## 2. Алгоритмы поиска

### Задача 11. Линейный поиск

Напиши функцию `linearSearch(arr, target)`, которая возвращает индекс искомого элемента. Если элемент не найден, возвращай `-1`.

```js
const arr = [14, 7, 22, 3, 18, 9];
const target = 18;
```

### Задача 12. Бинарный поиск

Напиши функцию `binarySearch(arr, target)`, которая ищет число в отсортированном массиве методом деления диапазона пополам. Не используй `indexOf()` и `includes()`.

```js
const arr = [2, 5, 8, 12, 16, 23, 38, 56];
const target = 23;
```

### Задача 13. Первое вхождение

Напиши функцию `firstOccurrence(arr, target)`, которая возвращает индекс первого вхождения числа в отсортированном массиве с повторениями. Используй бинарный поиск.

```js
const arr = [1, 2, 2, 2, 3, 4, 4, 5];
const target = 2;
```

### Задача 14. Последнее вхождение

Напиши функцию `lastOccurrence(arr, target)`, которая возвращает индекс последнего вхождения числа в отсортированном массиве. Используй бинарный поиск.

```js
const arr = [1, 2, 2, 2, 3, 4, 4, 5];
const target = 2;
```

### Задача 15. Количество вхождений

Напиши функцию `countOccurrences(arr, target)`, которая считает количество повторений числа в отсортированном массиве. Попробуй добиться сложности `O(log n)`.

```js
const arr = [1, 2, 2, 2, 3, 4, 4, 5];
const target = 2;
```

### Задача 16. Поиск пары чисел

Напиши функцию `findPair(arr, target)`, которая находит два элемента, сумма которых равна `target`. Если пара не найдена, возвращай `null`. Один элемент нельзя использовать дважды.

```js
const arr = [4, 7, 1, 9, 3, 6];
const target = 10;
```

## 3. Алгоритмы сортировки

Для задач 17–21 используй исходный массив:

```js
const arr = [7, 3, 9, 1, 5, 3, 8, 2];
```

### Задача 17. Сортировка пузырьком

Напиши функцию `bubbleSort(arr)`. Не используй `sort()`. Сравнивай соседние элементы и меняй их местами, если они расположены неправильно.

### Задача 18. Сортировка выбором

Напиши функцию `selectionSort(arr)`. На каждом шаге находи минимальный элемент неотсортированной части и ставь его на нужную позицию.

### Задача 19. Сортировка вставками

Напиши функцию `insertionSort(arr)`. Последовательно вставляй каждый элемент в правильное место отсортированной части массива.

### Задача 20. Сортировка слиянием

Напиши функцию `mergeSort(arr)`. Реализуй алгоритм с разделением массива на части, рекурсивной сортировкой и слиянием.

### Задача 21. Быстрая сортировка

Напиши функцию `quickSort(arr)`. Реализуй алгоритм с опорным элементом и рекурсивной сортировкой частей массива.

### Задача 22. Сортировка подсчётом

Напиши функцию `countingSort(arr)` для сортировки целых неотрицательных чисел. Не используй `sort()`.

```js
const arr = [4, 2, 2, 8, 3, 3, 1, 0, 4];
```

### Задача 23. Сравнение сортировок

Сравни Bubble Sort, Selection Sort, Insertion Sort, Merge Sort и Quick Sort. Измерь время выполнения с помощью `performance.now()`. Перед каждым измерением используй копию исходного массива.

```js
const small = Array.from({ length: 100 }, () =>
  Math.floor(Math.random() * 1000)
);

const medium = Array.from({ length: 1000 }, () =>
  Math.floor(Math.random() * 1000)
);

const large = Array.from({ length: 10000 }, () =>
  Math.floor(Math.random() * 1000)
);
```

## 4. Строки и подсчёт частот

### Задача 24. Проверка палиндрома

Напиши функцию `isPalindrome(str)`, которая проверяет, читается ли строка одинаково в обоих направлениях. Игнорируй регистр и пробелы.

```js
const str = "Level";
```

### Задача 25. Проверка анаграмм

Напиши функцию `isAnagram(a, b)`, которая проверяет, состоят ли две строки из одинаковых символов с одинаковыми частотами.

```js
const a = "listen";
const b = "silent";
```

### Задача 26. Первый уникальный символ

Напиши функцию `firstUniqueChar(str)`, которая возвращает первый символ, встречающийся ровно один раз. Если уникальных символов нет, возвращай `null`.

```js
const str = "swiss";
```

### Задача 27. Самый частый символ

Напиши функцию `mostFrequentChar(str)`, которая возвращает самый часто встречающийся символ. При равной частоте выбирай тот, который раньше встречается в строке.

```js
const str = "aabbbccccdd";
```

### Задача 28. Подсчёт вхождений подстроки

Напиши функцию `countSubstring(str, sub)`, которая считает количество вхождений подстроки, включая пересекающиеся. Не используй регулярные выражения и `match()`.

```js
const str = "abababa";
const sub = "aba";
```

### Задача 29. Сжатие строки

Напиши функцию `compressString(str)`, которая заменяет последовательности одинаковых символов символом и числом повторений.

```js
const str = "aaabbccccdaa";
```

### Задача 30. Факториал

Напиши функцию `factorial(n)`, вычисляющую факториал числа с помощью рекурсии.

const n = 5;

### Задача 31. Числа Фибоначчи

Напиши функцию `fibonacci(n)`, которая возвращает `n`-е число Фибоначчи. Реализуй рекурсивную и итеративную версии.

### Задача 32. Сумма цифр

const n = 5831;

### Задача 33. Реализация стека

Создай класс `Stack` с методами `push`, `pop`, `peek` и `isEmpty`.

stack.push(10);
stack.push(20);
stack.push(30);

stack.peek();
stack.pop();
stack.pop();
stack.peek();

const values = [10, 20, 30, 40];

## 6. Сложность алгоритмов и дополнительные задачи

### Задача 37. Оценка сложности алгоритмов

Для каждого фрагмента определи временную и дополнительную пространственную сложность в нотации Big O.

**Фрагмент A**

```js
function exampleA(arr) {
  for (let i = 0; i < arr.length; i++) {
    console.log(arr[i]);
  }
}
```

**Фрагмент B**

```js
function exampleB(arr) {
  for (let i = 0; i < arr.length; i++) {
    for (let j = 0; j < arr.length; j++) {
      console.log(arr[i], arr[j]);
    }
  }
}
```

**Фрагмент C**

```js
function exampleC(n) {
  while (n > 1) {
    n = Math.floor(n / 2);
  }
}
```

**Фрагмент D**

```js
function exampleD(arr) {
  console.log(arr[0]);
}
```

### Задача 38. Максимальная сумма подмассива

Напиши функцию `maxSubarraySum(arr)`, которая находит максимальную сумму непрерывного подмассива.

```js
const arr = [-2, 1, -3, 4, -1, 2, 1, -5, 4];
```

### Задача 39. Слияние интервалов

Напиши функцию `mergeIntervals(intervals)`, которая объединяет пересекающиеся интервалы. Учти, что интервалы могут быть не отсортированы.

```js
const intervals = [
  [1, 3],
  [2, 6],
  [8, 10],
  [9, 12],
  [15, 18]
];
```

### Задача 40. Поиск пропущенного числа

Напиши функцию `findMissingNumber(arr, n)`, которая находит одно пропущенное число в последовательности от `1` до `n`. Повторений нет.

```js
const arr = [1, 2, 3, 5, 6, 7];
const n = 7;
```

### Задача 41. Поиск дубликатов

Напиши функцию `hasDuplicates(arr)`, которая возвращает `true`, если в массиве есть повторяющиеся значения, и `false` в противном случае. Постарайся добиться временной сложности `O(n)`.

```js
const arr1 = [1, 2, 3, 4, 2];
const arr2 = [1, 2, 3, 4, 5];
```

### Задача 42. Поиск пересечения массивов

Напиши функцию `intersection(a, b)`, которая возвращает уникальные значения, присутствующие в обоих массивах. Не используй `filter()` вместе с `includes()`.

```js
const a = [1, 2, 2, 3, 4, 5];
const b = [2, 3, 3, 5, 6];
```

## Как работать с задачами

* Решай задачи по порядку или выбирай отдельные разделы.
* Проверяй решения на исходных данных и дополнительных граничных случаях.
* По возможности анализируй временную и пространственную сложность.
* Не изменяй исходный массив, если условие этого не допускает.
* Для каждой задачи можешь создать отдельный файл в папке `solutions/`.
